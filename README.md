# CodeK Website

Bilingual Arabic/English company website built with HTML, CSS, JavaScript, and Bootstrap 5, following the CodeK design system.

## Features
- Arabic RTL and English LTR language toggle
- Dark and light themes, saved in local storage
- Responsive sections for services, selected work, about, process, and contact
- Readex Pro typography and CodeK violet/night palette
- Accessible labels, reduced-motion support, and responsive mobile navigation

## Before publishing
- Replace the illustrative work cards with verified CodeK projects and their URLs.
- Add the official CodeK inbox in the `inbox` constant near the end of `index.html` to enable the contact form.
- Add verified company social links/contact details where indicated.

Open `index.html` directly or publish the repository with GitHub Pages.
